A dependency-free, byte-exact reimplementation of makefun-site 1.0.0's static-site builder, optimized for CPU time: a fused markdown/template pipeline, templates compiled to JavaScript, and per-case memoization of includes, links, and slugs. About 3x faster than the house baseline on the practice set (local CPU ~195 ms vs ~571 ms).

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
